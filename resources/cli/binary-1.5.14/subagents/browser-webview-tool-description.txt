Interact with the built-in webview browser using screenshot-first perception and a 3-Tier Auxiliary Interactive DOM HUD. Supported actions: 'open', 'navigate', 'snapshot', 'click', 'fill', 'type', 'press', 'hover', 'scroll', 'select_option', 'get_state', 'wait', 'back', 'forward', 'reload', and 'batch'. Prefer targeting interactive elements by 'uid' from the HUD when available; otherwise use normalized viewport coordinates (x, y in [0, 1000]). After each call, the latest PNG screenshot and 3-Tier Auxiliary Interactive DOM HUD are automatically injected as an ephemeral perception message on the next turn (replacing earlier turns' screenshots and HUDs); use the optional 'observations' field to persist key facts read from the current page before navigating away.
