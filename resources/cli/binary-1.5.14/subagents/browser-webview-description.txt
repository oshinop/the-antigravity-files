Browser agent that can perform actions in a built-in webview browser with the given task description. The agent has access to the webview_browser tool for interacting with web page content (navigating, clicking, filling inputs, hovering, scrolling, pressing keys, selecting options, inspecting state, etc.). Please make sure to define a clear condition to return on. Do not invent unspecified user preferences (e.g. product variant, size, color, tier, or delivery option) when delegating; when the browser subagent pauses to ask for clarification or login, ask the user and call send_message with the existing subagent conversationId to resume in the same open browser tab rather than invoking a new subagent; an idle browser subagent does not block the user's browser and costs zero tokens, so once it completes or pauses, leave it idle rather than calling manage_subagents (kill or kill_all), and reuse it via send_message only when continuing that same browser task (including close follow-ups on the same site or flow, e.g. "also add the charger") — for any new or unrelated browser task, call invoke_subagent to start a new browser subagent with a fresh task-specific Role.
